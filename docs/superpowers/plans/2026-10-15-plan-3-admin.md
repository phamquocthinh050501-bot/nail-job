# Trang admin: Kế hoạch triển khai (Kế hoạch 3/3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dựng trang quản trị: đăng nhập admin, khung có sidebar co giãn, tổng quan, lịch hẹn (xác nhận, hoàn thành, hủy, thêm lịch, gửi nhắc mô phỏng), dịch vụ, thợ và giờ mở cửa, khách hàng (điểm, đặt lại PIN), khuyến mãi, doanh thu có biểu đồ; có test và kiểm thử trình duyệt.

**Architecture:** Các trang CRUD (dịch vụ, thợ, khuyến mãi) dùng **một bộ điều khiển bằng config** (`ResourcePage`, `DataTable`, `ResourceForm`) để không viết bảng và form riêng cho từng loại. Số liệu doanh thu do hàm SQL tính (đúng múi giờ Việt Nam, chỉ lịch hoàn thành). Quyền do RLS và hàm `is_admin()` của CSDL quyết định; giao diện chỉ chuyển hướng.

**Tech Stack:** Như Kế hoạch 2, thêm Recharts (biểu đồ) và Supabase Edge Function (Deno) cho việc đặt lại PIN.

**Spec:** `docs/superpowers/specs/2026-10-15-nail-salon-web-design.md` (mục 9, 11.9 đến 11.17, 7.6, 7.7, 8). **Quy chuẩn:** `docs/CODING_STANDARDS.md`. **Điều kiện:** Kế hoạch 1 và 2 đã xong; đã tạo tài khoản admin (README); project Supabase thử nghiệm.

**Khác biệt có chủ ý so với spec:**
- "Tuần này" = **7 ngày gần nhất tính cả hôm nay** (cùng khung với biểu đồ 7 ngày); "Tháng này" = từ ngày 1 đến hôm nay. So sánh tuần dùng 7 ngày liền trước.
- Dữ liệu "Số lần đến" và "Lần cuối" của khách tính ở hàm SQL `admin_customers()`.
- Tìm kiếm tên và SĐT làm ở trình duyệt, **không phân biệt dấu** (gõ `nguyen` tìm ra `Nguyễn`), vì một tiệm có ít khách và tránh cài thêm tiện ích CSDL.
- Việc đặt lại PIN cần khóa dịch vụ (service-role) nên chạy trong **Edge Function**, không bao giờ trong trình duyệt. Hàm này **kiểm tra tay** (không có test tự động), nêu rõ ở Task 9.

## Global Constraints

- Giao diện tiếng Việt; giá `350.000đ` qua `formatVnd`; ngày giờ qua `lib/format.ts` và `lib/vnTime.ts`.
- Trạng thái lịch lấy từ `BOOKING_STATUS`; nút hành động lấy từ `ADMIN_ACTION` trong `config/admin.ts` (một nơi).
- Component và page **không** gọi `supabase` trực tiếp; mọi truy vấn qua `src/lib/api/admin.ts` hoặc `resources.ts`.
- Mọi truy vấn hiển thị qua `<QueryState>`; xác nhận mọi hành động nguy hiểm (Hủy, Hoàn thành, Xóa) bằng `ConfirmDialog`.
- Vùng chạm tối thiểu 44px; nút Xác nhận/Hoàn thành to đủ chạm bằng một tay trên điện thoại; mọi biểu đồ có bảng số liệu thay thế.
- Admin xác định bởi `profiles.role = 'admin'`; không có trang đăng ký admin. Không đưa khóa dịch vụ (service-role) vào mã trình duyệt.
- Điểm ngắt: dưới 768px (menu ☰), từ 768px (sidebar thu gọn icon), từ 1024px (sidebar đủ chữ). Không cuộn ngang ở 375, 768, 1280.
- Doanh thu chỉ tính lịch `completed`, theo `total_vnd`, theo ngày `completed_at` ở múi giờ Việt Nam.

```ts
export async function signInAdmin(v: { email: string; password: string }) {
  const { data, error } = await supabase.auth.signInWithPassword(v);
  if (error) throw new AppError('badCredentials');
  const profile = await supabase.from('profiles').select('role').eq('id', data.user.id).single();
  if (profile.data?.role !== 'admin') {
    await supabase.auth.signOut();
    throw new AppError('forbidden');
  }
}
```

```tsx
import { Navigate, Outlet } from 'react-router-dom';
import { Skeleton } from '@/components/ui/Skeleton';
import { ROUTES } from '@/config/routes';
import { useAuth } from '@/features/auth/AuthProvider';
import { useProfile } from '@/features/auth/queries';

// Chỉ chuyển hướng cho gọn. Quyền thật do RLS và is_admin() của CSDL quyết định.
export function RequireAdmin() {
  const { session, loading } = useAuth();
  const profile = useProfile();
  if (loading || (session && profile.isPending)) return <Skeleton className="m-8 h-64" />;
  if (!session) return <Navigate to={ROUTES.admin.login} replace />;
  if (profile.data?.role !== 'admin') return <Navigate to={ROUTES.home} replace />;
  return <Outlet />;
}
```

```tsx
import { zodResolver } from '@hookform/resolvers/zod';
import { useForm } from 'react-hook-form';
import { useNavigate } from 'react-router-dom';
import { toast } from 'sonner';
import { Button } from '@/components/ui/Button';
import { Field, Input } from '@/components/ui/Field';
import { ROUTES } from '@/config/routes';
import { SITE } from '@/config/site';
import { adminLoginSchema, type AdminLoginForm } from '@/features/admin/schemas';
import { signInAdmin } from '@/lib/auth';
import { toUserMessage } from '@/lib/errors';

export function AdminLoginPage() {
  const navigate = useNavigate();
  const { register, handleSubmit, formState: { errors, isSubmitting } } = useForm<AdminLoginForm>({
    resolver: zodResolver(adminLoginSchema),
  });
  return (

        </Field>
        <Field label="Mật khẩu" required error={errors.password?.message}>
          {(a) => <Input {...a} {...register('password')} type="password" autoComplete="current-password" />}
        </Field>
        <Button type="submit" disabled={isSubmitting}>Đăng nhập</Button>
```

```ts
import type { ReactNode } from 'react';
import { z } from 'zod';
import { COPY } from '@/config/copy';

export type FieldType = 'text' | 'textarea' | 'vnd' | 'number' | 'select' | 'switch' | 'date';

export type FieldDef = {
  key: string;
  label: string;
  type: FieldType;
  required?: boolean;
  hint?: string;
  options?: { value: string; label: string }[];
  min?: number;
  max?: number;
};

export type Column<T> = { key: string; label: string; cell: (row: T) => ReactNode };

export type ResourceConfig<T extends { id: string }> = {
  table: string;
  title: string;
  addLabel: string;
  emptyTitle: string;
  orderBy: string;
  fields: FieldDef[];
  columns: Column<T>[];
  // Ghi đè khi cần quy tắc riêng (ví dụ ngày kết thúc phải sau ngày bắt đầu).
  schema?: z.ZodTypeAny;
  // Đổi dữ liệu dòng sang giá trị ô nhập, và ngược lại, khi hai dạng khác nhau.
  toForm?: (row: T) => Record<string, unknown>;
  toRow?: (values: Record<string, unknown>) => Record<string, unknown>;
};

const numeric = (f: FieldDef) =>
  z
    .string()
    .regex(/^\d+$/, COPY.validation.integer)
    .transform(Number)
    .pipe(
      z
        .number()
        .min(f.min ?? 0, `Giá trị tối thiểu là ${f.min ?? 0}.`)
        .max(f.max ?? 1_000_000_000, `Giá trị tối đa là ${f.max ?? 1_000_000_000}.`),
    );

export function buildSchema(fields: FieldDef[]) {
  const shape: Record<string, z.ZodTypeAny> = {};
  for (const f of fields) {
    switch (f.type) {
      case 'vnd':
      case 'number':
        shape[f.key] = numeric(f);
        break;
      case 'switch':
        shape[f.key] = z.boolean();
        break;
      case 'select':
      case 'date':
        shape[f.key] = z.string().min(1, COPY.validation.required);
        break;
      case 'textarea':
        shape[f.key] = z.string();
        break;
      default:
        shape[f.key] = f.required ? z.string().trim().min(1, COPY.validation.required) : z.string().trim();
    }
  }
  return z.object(shape);
}

export function fieldDefaults(fields: FieldDef[], row?: Record<string, unknown>) {
  const out: Record<string, unknown> = {};
  for (const f of fields) {
    const value = row?.[f.key];
    out[f.key] = f.type === 'switch' ? Boolean(value) : value === null || value === undefined ? '' : String(value);
  }
  return out;
}

export const toPayload = (values: Record<string, unknown>) =>
  Object.fromEntries(Object.entries(values).map(([k, v]) => [k, v === '' ? null : v]));
```

```ts
import { useMutation, useQuery, useQueryClient } from '@tanstack/react-query';
import { deleteRow, insertRow, listRows, updateRow } from '@/lib/api/resources';
import { queryKeys } from '@/lib/queryKeys';

export const useResourceRows = <T>(table: string, orderBy: string) =>
  useQuery({ queryKey: queryKeys.admin('rows', table), queryFn: () => listRows<T>(table, orderBy) });

// Mọi thay đổi làm mới toàn bộ dữ liệu admin và danh mục công khai (giá, ẩn/hiện dịch vụ).
function useRefresh() {
  const client = useQueryClient();
  return () => Promise.all([client.invalidateQueries({ queryKey: ['admin'] }), client.invalidateQueries()]);
}

export function useSaveRow(table: string) {
  const refresh = useRefresh();
  return useMutation({
    mutationFn: (v: { id?: string; values: Record<string, unknown> }) =>
      v.id ? updateRow(table, v.id, v.values) : insertRow(table, v.values),
    onSuccess: refresh,
  });
}

export function useDeleteRow(table: string) {
  const refresh = useRefresh();
  return useMutation({ mutationFn: (id: string) => deleteRow(table, id), onSuccess: refresh });
}
```

```tsx
export function ResourceForm({ fields, schema, defaults, pending, onSubmit }: Props) {

            name={f.key}
            control={control}
            render={({ field }) => <Switch label={f.label} checked={Boolean(field.value)} onCheckedChange={field.onChange} />}
          />

          <Field key={f.key} label={f.label} required={f.required} hint={f.hint} error={error(f.key)}>

              f.type === 'textarea' ? (
                <Textarea {...a} {...register(f.key)} />
              ) : f.type === 'select' ? (
                <select {...a} {...register(f.key)} className={inputClass}>

                </select>

                  {...register(f.key)}
```

```tsx
// Một trang quản lý bất kỳ (dịch vụ, thợ, khuyến mãi) chỉ khác nhau ở `config`.
export function ResourcePage<T extends { id: string }>({ config }: { config: ResourceConfig<T> }) {
  const rows = useResourceRows<T>(config.table, config.orderBy);
  const save = useSaveRow(config.table);
  const remove = useDeleteRow(config.table);
  const [editing, setEditing] = useState<T | 'new' | null>(null);
  const [deleting, setDeleting] = useState<T | null>(null);

  const schema = config.schema ?? buildSchema(config.fields);
  const current = editing && editing !== 'new' ? editing : undefined;
  const defaults = fieldDefaults(config.fields, current ? (config.toForm ? config.toForm(current) : (current as never)) : undefined);

  const submit = (values: Record<string, unknown>) =>
    save.mutate(
      { id: current?.id, values: toPayload(config.toRow ? config.toRow(values) : values) },
      {
        onSuccess: () => {
          toast.success('Đã lưu');
          setEditing(null);
        },
        onError: (e) => toast.error(toUserMessage(e)),
      },
    );

  return (
    <div className="grid gap-6">
      <div className="flex items-center justify-between gap-3">
        <h2 className="text-2xl font-extrabold">{config.title}</h2>
        <Button onClick={() => setEditing('new')}>
          <Plus aria-hidden="true" className="size-5" />
          {config.addLabel}
        </Button>
      </div>

      <QueryState query={rows} isEmpty={(r) => r.length === 0} empty={<EmptyState title={config.emptyTitle} />}>

            rows={data}
            rowKey={(r) => r.id}
            columns={config.columns}
            actions={(r) => (
              <>
                <Button size="sm" variant="secondary" onClick={() => setEditing(r)}>{COPY.actions.edit}</Button>
                <Button size="sm" variant="danger" onClick={() => setDeleting(r)}>{COPY.actions.delete}</Button>
              </>
            )}
          />
        )}
      </QueryState>

      <Drawer open={editing !== null} onOpenChange={(open) => !open && setEditing(null)} title={current ? 'Sửa' : config.addLabel}>
        {editing !== null && (
          // key ép form khởi tạo lại giá trị mặc định mỗi lần mở một dòng khác
```

```ts
import { BOOKING_STATUS_LIST, type BookingStatus } from '@/config/statuses';
import { fold } from '@/lib/text';
import type { AdminBooking } from './types';

export function statusCounts(rows: { status: BookingStatus }[]): Record<BookingStatus, number> {
  const counts = Object.fromEntries(BOOKING_STATUS_LIST.map((s) => [s, 0])) as Record<BookingStatus, number>;
  for (const r of rows) counts[r.status] += 1;
  return counts;
}

export function filterAppointments(rows: AdminBooking[], status: BookingStatus | 'all', query: string) {
  const q = fold(query);
  return rows.filter(
    (r) =>
      (status === 'all' || r.status === status) &&
      (q === '' || fold(r.customers.full_name).includes(q) || r.customers.phone.includes(q)),
  );
}
```

```ts
import { addDays } from '@/lib/vnTime';

export function periodRange(period: Period, today: string): { from: string; to: string } {
  if (period === 'today') return { from: today, to: today };
  if (period === 'week') return { from: addDays(today, -6), to: today };
  return { from: `${today.slice(0, 8)}01`, to: today };
}
```

```ts
export function trendText(current: number, previous: number): string {
  if (previous === 0) return 'Tuần trước chưa có doanh thu';
  if (current === previous) return 'Bằng tuần trước';
  const pct = Math.round((Math.abs(current - previous) / previous) * 100);
  return `${current > previous ? 'Tăng' : 'Giảm'} ${pct}% so với tuần trước`;
}
```

```ts
import { isoToVn, timeToMinutes, weekdayOf } from '@/lib/vnTime';

// Giờ dạng 'HH:MM'. Một hàng cho mỗi thứ trong tuần (0 = Chủ nhật).
export type WeekRow = { weekday: number; start: string; end: string; off: boolean };

export function validateWeek(rows: WeekRow[], bound?: WeekRow[]): Record<number, string> {
  const errors: Record<number, string> = {};
  for (const r of rows) {
    const limit = bound?.find((b) => b.weekday === r.weekday);
    if (r.off) continue;
    if (limit?.off) {
      errors[r.weekday] = 'Tiệm nghỉ ngày này nên thợ không thể làm.';
    } else if (timeToMinutes(r.end) <= timeToMinutes(r.start)) {
      errors[r.weekday] = 'Giờ kết thúc phải sau giờ bắt đầu.';
    } else if (limit && (timeToMinutes(r.start) < timeToMinutes(limit.start) || timeToMinutes(r.end) > timeToMinutes(limit.end))) {
      errors[r.weekday] = `Giờ làm phải nằm trong giờ mở cửa (${limit.start} đến ${limit.end}).`;
    }
  }
  return errors;
}

type Booked = { code: string; start_at: string; end_at: string; staff_id: string };

// Lịch đã đặt nằm ngoài giờ làm mới. Chỉ để cảnh báo; không tự hủy lịch nào.
export function findAffected(bookings: Booked[], rows: WeekRow[], staffId?: string) {
  return bookings
    .filter((b) => !staffId || b.staff_id === staffId)
    .filter((b) => {
      const start = isoToVn(b.start_at);
      const end = isoToVn(b.end_at);
      const day = rows.find((r) => r.weekday === weekdayOf(start.day));
      if (!day || day.off) return true;
      return start.minutes < timeToMinutes(day.start) || end.minutes > timeToMinutes(day.end);
    })
    .map(({ code, start_at }) => ({ code, start_at }));
}
```

```ts
// Chạy trên Deno của Supabase. Đặt lại PIN cho khách cần quyền cao nên chỉ làm ở máy chủ.
import { createClient } from 'https://esm.sh/@supabase/supabase-js@2';

const cors = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};
const json = (body: unknown, status = 200) =>
  new Response(JSON.stringify(body), { status, headers: { ...cors, 'Content-Type': 'application/json' } });

Deno.serve(async (req) => {
  if (req.method === 'OPTIONS') return new Response('ok', { headers: cors });

  const authorization = req.headers.get('Authorization');
  if (!authorization) return json({ error: 'forbidden' }, 401);

  // 1. Xác minh người gọi là admin bằng chính JWT của họ (qua hàm is_admin() và RLS).
  const asCaller = createClient(Deno.env.get('SUPABASE_URL')!, Deno.env.get('SUPABASE_ANON_KEY')!, {
    global: { headers: { Authorization: authorization } },
  });
  const { data: isAdmin, error: adminError } = await asCaller.rpc('is_admin');
  if (adminError || isAdmin !== true) return json({ error: 'forbidden' }, 403);

  // 2. Kiểm tra dữ liệu vào.
  const { customer_id, pin } = await req.json().catch(() => ({}));
  if (typeof customer_id !== 'string' || typeof pin !== 'string' || !/^\d{6}$/.test(pin)) {
    return json({ error: 'bad_request' }, 400);
  }

  // 3. Dùng quyền dịch vụ để đổi mật khẩu của đúng khách đó.
  const asService = createClient(Deno.env.get('SUPABASE_URL')!, Deno.env.get('SUPABASE_SERVICE_ROLE_KEY')!);
  const { data: customer } = await asService.from('customers').select('profile_id').eq('id', customer_id).single();
  if (!customer?.profile_id) return json({ error: 'no_account' }, 404);

  const { error } = await asService.auth.admin.updateUserById(customer.profile_id, { password: pin });
  if (error) return json({ error: 'update_failed' }, 500);
  return json({ ok: true });
});
```
